새 문서 등록

RAG Pipeline

문서를 등록하면 마크다운 변환, 청킹, 임베딩 파이프라인이 순차적으로 자동 진행됩니다.

최대 1개 파일만 업로드 가능
upload_file 클릭하여 파일 선택 지원 형식: PDF, DOCX, PPTX, XLSX, MD, ADOC, HTML, CSV, 이미지 (파일당 최대 50MB)
draft
check_circle 준비 완료
•유효성 검증 통과
auto_awesome 자동 색인 파이프라인 처리 안내
비동기 백그라운드 구동
1 대기 및 등록 파일 정합성 확인
2 마크다운 변환 표·본문 구조화
3 청킹 처리 최적 토큰 분할
4 임베딩 완료 벡터 DB 저장
check 문서 등록 완료 즉시 [대기] 상태로 등록되며, 모든 단계가 순차적으로 자동 실행됩니다.
